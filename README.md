# ngo

> **ngo2 status:** This branch is a clean rewrite around
> [aspen-tree](https://github.com/potassco/aspen-tree). Predicate detection, cleanup, unused, inline, and symmetry are implemented; the remaining trait
> documentation and tests are retained as a roadmap and their API flags currently raise `NotImplementedError`.

ngo is a program and python library to optimize non ground logic ASP encodings for performance.
Please read [the documentation](https://docs.potassco.org/ngo/).

You can get more information about [contributing](https://github.com/potassco/ngo/blob/main/CONTRIBUTING.md) and [development](https://github.com/potassco/ngo/blob/main/DEVELOPMENT.md).
